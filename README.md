# React Tutorial

You will build a small tic-tac-toe game during this tutorial. This tutorial does not assume any existing React knowledge. The techniques you’ll learn in the tutorial are fundamental to building any React app, and fully understanding it will give you a deep understanding of React.

## Common Commit Types (Conventional Commits)

| Type | When to Use | Example |
| --- | --- | --- |
| `feat` | Adding new functionality visible to the user or expanding product capabilities | `feat: add "quantity" field to the product form` |
| `fix` | Fixing bugs and errors, resolving incorrect behavior | `fix: remove duplicates when saving the list` |
| `refactor` | Restructuring code without changing its behavior: simplifying, extracting logic, improving structure | `refactor: move filtering logic to a separate hook` |
| `style` | Formatting changes: indentation, quotes, linter fixes — no impact on logic | `style: fix indentation in ListItem.jsx` |
| `docs` | Updating documentation: README, comments, instructions | `docs: update installation instructions for dependencies` |
| `test` | Adding or modifying tests | `test: add unit test for the sum calculation function` |
| `build` | Changes related to builds, dependencies, or build config (Vite, Webpack, etc.) | `build: upgrade vite to 5.x` |
| `ci` | Changes to CI/CD configuration (GitHub Actions, GitLab CI, etc.) | `ci: add linter step to the pipeline` |
| `chore` | Maintenance tasks: cleanup, config updates, other miscellaneous changes | `chore: update .gitignore` |
| `perf` | Performance improvements: optimization, memoization, etc. | `perf: add memoization for the heavy component` |
